# FrameLoom

FrameLoom is a local desktop storyboard-asset archive for small film teams. Editors create durable JSON workspaces, import shot geometry and reference layers, annotate frames, render previews, stage CSV/JSON exports, and reopen the archive without losing state. The CLI exposes archive creation; focused packages separate persistence, domain validation, queries, rendering, staging, and notifications. Export cancellation is a normal user action and must not leave stale staging records for the next session.
